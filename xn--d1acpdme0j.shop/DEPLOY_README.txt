ОДЕЯЛКО — деплой на REG.RU (одеялко.shop / xn--d1acpdme0j.shop)
================================================================

ЧТО ЭТО
Полностью статический сайт «одеялко» + лёгкий PHP mock-API для витрин каталога,
подсказок адресов и демонстрационного оформления заказа. Node.js НЕ требуется.

КУДА РАСПАКОВАТЬ
1. Загрузите архив ODEYALKO_REG_RU.zip через файловый менеджер REG.RU
   в корневой каталог домена одеялко.shop (обычно это папка вида
   /var/www/u0000000/data/www/xn--d1acpdme0j.shop или www/одеялко.shop).
2. Распакуйте прямо в этот каталог: index.html и .htaccess должны оказаться
   в корне домена (не во вложенной папке).

ТРЕБОВАНИЯ ХОСТИНГА
- Apache с mod_rewrite (стандарт на виртуальном хостинге REG.RU) — обязателен.
- PHP любой версии 7.0+ (включён по умолчанию) — нужен ТОЛЬКО для папки /api/:
  витрины каталога на главной, подсказки города/улицы в корзине и
  демонстрационная отправка заказа. Без PHP сайт откроется, но эти блоки
  останутся пустыми.
- База данных НЕ требуется.
- Команды терминала, npm, node НЕ требуются.

SSL / HTTPS
В .htaccess включён редирект HTTP -> HTTPS и www -> без www.
Если SSL-сертификат ещё не выпущен, временно закомментируйте три строки
после комментария «HTTP -> HTTPS» (иначе браузер покажет ошибку сертификата),
затем верните их после выпуска сертификата (на REG.RU — бесплатный Let’s Encrypt).

ВАЖНО: ОФОРМЛЕНИЕ ЗАКАЗА — ДЕМОНСТРАЦИОННОЕ
Форма заказа показывает «Спасибо! Данные успешно отправлены», но данные
НИКУДА не отправляются и не сохраняются (api/procces.php). Для приёма реальных
заказов замените api/procces.php интеграцией с вашей CRM/почтой/оплатой.
